01 / GAME DEVELOPMENT

LIGTAS: A Gamified Flood Preparedness Simulation

LIGTAS is a A Gamified Flood Preparedness Simulation an interactive 3D mobile game designed to teach essential flood safety and disaster preparedness tailored for the Filipino context. Developed using Unity and C#, the game transforms critical survival scenarios into an engaging educational experience, challenging players to navigate environmental hazards and gather essential survival items. This was used for my Capstone project in my college and also presented in Game Expo Event in college week and made it to the 3rd place.

Disclaimer: This game was not published to any app stores due to financial constraints.
